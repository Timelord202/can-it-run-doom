# Can it run doom?

Can your device run doom? Only one way to find out!

To run this project locally, you'll need to create a `.env.local` file using `.env.example` as a template

Then, install the dependencies

```
pnpm install
pnpm run dev
```

That's it! Enter your device's specs to see if it can run the original doom!

(Alternatively, you can visit the website [here](https://can-it-run-doom-1d388dda77b6.herokuapp.com/))
